# BLOCK BLOOM

A cheerful, strategy-first block placement puzzle for web and mobile.

## Run locally
```bash
npm install
npm run dev
```

## Checks
```bash
npm test
npm run build
```

See [GAMEPLAY.md](./GAMEPLAY.md) for mechanics and [RELEASE.md](./RELEASE.md) for packaging notes.

The initial scaffold is browser-first and offline-friendly. Android packaging and production ad credentials require a local Android SDK and developer configuration; no store publication or production monetization is claimed.
